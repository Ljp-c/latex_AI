# make_origin_ready.py

把仪器导出的 XRD 原始 txt 重排成 **Origin 可以直接导入**的规整格式。

只依赖 Python 标准库（`re` / `sys` / `pathlib`），Python 3.9+ 即可运行，无需 pip 安装任何东西。

> 同目录下的 `plot_xrd_multi.py` 负责多曲线 + PDF 卡片绘图，是本次作业二使用的主脚本；`xrd_analysis.py` 包含峰拟合、Scherrer、Spurr–Myers、晶格参数等后续课程内容，本次作业不使用。用法见 `../README.md`。

## 快速开始

```powershell
cd E:\latex_AI\X-Ray\作业二

python .\脚本\make_origin_ready.py 资料\原数据            # 原始强度 -> 资料\原数据\ready\
python .\脚本\make_origin_ready.py 资料\原数据 --norm     # 归一化到 100 -> 资料\原数据\ready_norm\
python .\脚本\make_origin_ready.py 资料\原数据\200.txt    # 只处理一个文件
```

路径可以是相对路径（相对**当前工作目录**）或绝对路径。

## 参数

| 参数 | 说明 |
|---|---|
| `目录` | 处理该目录下所有 `*.txt`（**不递归**子目录），输出到该目录的 `ready\` 或 `ready_norm\` |
| `文件` | 只处理指定文件，输出到该文件所在目录的 `ready\` / `ready_norm\` |
| `-n` / `--norm` / `--normalize` | 强度归一化到最强峰 = 100 |
| 不给路径 | 处理当前工作目录下的 `*.txt` |

多个目录/文件可以混着传，输出目录以第一个目录（或第一个文件所在目录）为准。

退出码：`0` 成功；`1` 没找到任何 `.txt`。

## 输入格式（脚本的假设）

仪器导出的文件，GBK 编码、CRLF 换行：

```
实验日期:2026/9/29
文件路径:D:\2026年本科生实验\第四组\200.txt
样品序号:
实验者:User
起始角= 20
终止角= 80
步宽= 0.02
波长=1.54056
 0 kV,  0 mA
020.0200 119
020.0400 119
...
080.0000 34
```

逐行判定规则：

| 行的形态 | 处理方式 |
|---|---|
| 空行 | 跳过 |
| 匹配 `^\s*(\d{1,3}\.\d{4})\s+(\d+)\s*$` | 当作数据行：2θ 保留 4 位小数、强度为整数 |
| 含 `:` | 按第一个 `:` 拆成 `key: value` 存入元数据 |
| 含 `=` | 按第一个 `=` 拆成 `key= value` 存入元数据 |
| 其它（如 ` 0 kV,  0 mA`） | 忽略 |

实际用到的元数据键：`波长`、`步宽`、`起始角`、`终止角`、`实验日期`；缺哪个就在表头里写 `?`。

## 输出格式

**原始强度**（`ready\`）：

```
2θ→Intensity
°→counts
λ=1.54056 A; step 0.02°; 20-80°; 2026/9/29; Imax=216 @ 25.42°→sample 200
20.0200→119
20.0400→119
```

**归一化**（`ready_norm\`）：

```
2θ→I/I0
°→%
λ=1.54056 A; step 0.02°; 20-80°; 2026/9/29; Imax=216 @ 25.42°→sample 200
20.0200→55.09
20.0400→55.09
```

`→` 表示 **Tab**。三条约定：

1. **表头固定 3 行**，每行严格 2 个字段，依次对应 Origin 的 Long Name / Units / Comments 行。
2. **数据从第 4 行开始**，两列：`2θ` 与强度。
3. 编码保持 **GBK**、换行 **CRLF**，和源文件一致。

## 为什么是这个结构

Origin 的自动导入规则是：

- 字段数比数据行**少**的行 → 归入 Main Header
- 之后**头 3 个**字段数与数据一致的行 → 依次当成 列名 / 单位 / 备注

原始文件里 `起始角= 20`、`终止角= 80`、`步宽= 0.02` 恰好都是 2 字段，就被误判成了列名/单位/备注，而真正的元数据行掉进数据区。改成"3 行表头全部 2 字段 + 紧跟数据"，识别就不会出错。

## 归一化规则

```
I_norm = I / max(I) * 100
```

每个文件**各自**除以自己的最强峰，因此跨样品比较绝对强度时要注意这一点。备注里的 `Imax=…` 保留了归一化前的原始峰值和峰位，方便回溯。

## 已知限制

- 只支持**单列强度**。JADE 导出的多列（含计算值、差值）不适用。
- 强度必须是非负整数。若某行写成 `119.0`，不会被识别为数据行。
- 2θ 只接受 `0.0000`~`999.9999`（1~3 位整数 + 4 位小数）。
- `Å` 不在 GBK 字符集内，表头里统一写成 `A`（`λ=1.54056 A`）。
- 只扫描一层目录，不递归。

## 排错

| 现象 | 原因 / 处理 |
|---|---|
| `路径不存在：…`（退出码 1） | 传入的目录/文件名写错，或用了相对路径但当前目录不对 |
| `没有找到 .txt 文件（查找目录：…）`（退出码 1） | 目录对了但里面没有 txt；先确认打印出的目录对不对 |
| 某文件被 `跳过（没有识别到数据行）` | 数据行格式和正则不符，用文本编辑器看一眼实际行长 |
| Origin 里表头又串位了 | 检查输出文件表头是否仍是 3 行、每行 2 字段（手工编辑时容易把 Tab 弄丢或加列） |
| 中文显示成乱码 | 导入时 Encoding 要选 Chinese Simplified (GB2312)，不要选 UTF-8 |

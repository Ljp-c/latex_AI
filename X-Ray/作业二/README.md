## 脚本：make_origin_ready.py

### 为什么需要

仪器导出的 txt 长这样：

```
实验日期:2026/9/29
文件路径:D:\...\200.txt
样品序号:
实验者:User
起始角= 20
终止角= 80
步宽= 0.02
波长=1.54056
 0 kV,  0 mA
020.0200 119
020.0400 119
```

直接拖进 Origin 会遇到两个坑：

1. **逗号被当成列分隔符** —— 全文件唯一的逗号在 ` 0 kV,  0 mA` 这行，Origin 的 Auto 分隔符据此判定为逗号，数据行反而切不开，只剩一列。
2. **自动表头识别错位** —— Origin 的规则是"字段数比数据行少的行算 Main Header，之后头 3 个字段数与数据一致的行依次当列名/单位/备注"。原来 `起始角= 20`、`终止角= 80`、`步宽= 0.02` 都只有两个字段，就被当成了列名/单位/备注。

### 做法

把文件重排成**3 行表头 + Tab 分隔的两列数据**，三行表头每行都严格 2 个字段，数据从第 4 行开始，Origin 的自动识别就不会再猜错。

输出格式：

```
2θ→I/I0
°→%
λ=1.54056 A; step 0.02°; 20-80°; 2026/9/29; Imax=216 @ 25.42°→sample 200
20.0200→55.09
20.0400→55.09
```

`→` 表示 Tab。三行分别对应 Origin 的 Long Name / Units / Comments 行。

### 用法

```powershell
cd E:\latex_AI\X-Ray\作业二

python .\脚本\make_origin_ready.py 资料\原数据              # 原始强度 -> 资料\原数据\ready\
python .\脚本\make_origin_ready.py 资料\原数据 --norm       # 归一化 -> 资料\原数据\ready_norm\
python .\脚本\make_origin_ready.py 资料\原数据\200.txt -n   # 只处理单个文件
```

| 参数 | 说明 |
|---|---|
| 目录路径 | 处理该目录下所有 `.txt`，输出到该目录的 `ready/` 或 `ready_norm/` |
| 文件路径 | 只处理指定文件 |
| `-n` / `--norm` / `--normalize` | 归一化到最强峰 = 100 |
| 不给路径 | 处理当前工作目录 |

原数据只读，脚本不会改动源文件，只往新目录里写。

### Origin 导入

生成的文件直接拖进 Origin 窗口即可。若要更保险，用一次 `Data → Import from File → Import Wizard…`：

- Encoding：Chinese Simplified (GB2312)
- Delimiter：只勾 Tab
- Header Lines：Column Name = 1、Units = 1、Comments = 1、Main Header = 0
- 最后 `Save Filter` 存成如 `XRD`，以后 `Data → Import from File → XRD` 一键导入

## 脚本：plot_xrd_multi.py

### 功能

- 读取 `资料/原数据/ready_norm/` 的已归一化数据；
- 按 200–900 °C 偏移叠成多曲线；
- 在下方画锐钛矿 71-1167 / 金红石 75-1756 的 PDF 卡片棒图；
- 给出 23–30° 局部放大；
- 输出 `课程论文/assets/xrd/fig1_xrd_stack.pdf/png`。

本脚本只做绘图，不做峰拟合、Scherrer 尺寸、Spurr–Myers 相含量或晶格参数精修。

### 用法

```powershell
cd E:\latex_AI\X-Ray\作业二
python .\脚本\plot_xrd_multi.py
```

依赖 numpy、matplotlib。

| `make_origin_ready.py` | 原始 txt → 3 行表头 + Tab，归一化 | 使用 |

### 结果概述

- 200 °C：低结晶度锐钛矿，25.4° 宽包；
- 300–600 °C：锐钛矿，主要峰 25.4 (101)、37.8 (004)、48.0 (200)、54.0 (105)、55.1 (211)；
- 700 °C：27.6° 出现金红石 (110)；
- 800 °C：两相共存；
- 900 °C：金红石。

PDF 卡片：Jade 中检索到的锐钛矿 71-1167、金红石 75-1756；常用编号 21-1272/21-1276 的主峰位置一致。

### 说明

- 200–900 按热处理温度（°C）处理；
- 本作业只做定性物相描述，不做峰拟合/定量分析；
- 原始数据只读，脚本只往 `ready/`、`ready_norm/` 和 `课程论文/assets/xrd/` 写。

## 注意

- 输出保持 **GBK 编码**：备注里的中文、`°`、`θ`、`λ` 都能编码；`Å` 不在 GBK 字符集内，统一写成 `A`。
- 归一化是**每个文件各自**除以自己的最强峰，跨样品比较峰形时注意这一点。
- 表头三行必须保持 2 个字段，手工编辑时别把 Tab 删掉或加列。

④ 能级关系（必背）

Ee ≫ Ev > Er　（电子 ≫ 振动 > 转动）
  • ΔE = hν = hc/λ；ΔEe 最大（约 1–20 eV，1 eV = 1.6×10-19 J）
  • 振动能级 > 转动能级、< 电子能级
  • 振动光谱中涵盖转动光谱 → IR 又叫"振动-转动光谱"
  • 三者都量子化；只有光能 = 两能级差才被吸收

⑨ 不饱和度 Ω（缺氢指数）

Ω = 1 + n4 + (n3 − n1)/2

① 分子轨道

轨道形成特点
σ两个 p 轨道"头对头"绕键轴对称；σp、σp*
π两个 p 轨道"肩并肩"绕键轴非对称；πp、πp*
n原子上的未用电子对非成键轨道，没有反键轨道
  • 位相相同重叠 → 成键轨道（能量低于原子轨道）
  • 位相相反重叠 → 反键轨道 Ψ\*（能量高于原子轨道）
  • 原子轨道相互作用越大，分子轨道越稳定

② 紫外光谱的产生

  • 分子吸收紫外/可见光 → 价键电子由基态跃迁到激发态（反键轨道）
  • 相邻电子能级差 ≈ 1–20 eV
  • 只有光能 = 跃迁能量才吸收；吸收与化学键类型有关
  • 为什么是带状光谱：电子跃迁总伴随振动、转动能级改变 → 大量密集子能级叠加

③ 紫外吸收光谱能提供什么

参数信息

局限：UV 只能反映共轭体系的特征，不能给出官能团全貌，也不能定碳骨架。

（六）吸收强度

εmax = 0.87×1020 · P · a
  • P = 跃迁概率(0~1)；a = 发色团靶面积
  • 允许跃迁：按选律可能 → 概率大 → 吸收强
  • 禁阻跃迁：按选律不可能 → 极弱甚至观察不到（n→π*）
  • 发色团共轭越长，εmax 越大
经典问答：为什么 π→π* 的 ε 远大于 n→π*？
→ π→π* 是允许跃迁、靶面积大；n→π* 是禁阻跃迁（n 与 π* 轨道空间重叠差）、跃迁概率小。

（1）电负性（诱导效应）

电负性强的基团通过诱导使氢核周围电子云密度降低 → 屏蔽减弱 → δ 增大（低场）。

（2）磁的各向异性效应（最易考）

π 键电子流动产生小诱导磁场，通过空间影响邻近氢核：

  • 与外场方向相反 → 削弱外场 → 正屏蔽，δ 减小（高场）

① 自旋偶合与裂分

  • 自旋-自旋偶合：相邻核自旋产生磁场，通过成键电子传递而相互干扰
  • 自旋-自旋裂分：由偶合引起共振峰分裂成多个峰
  • 偶合常数 J：裂分后两个小峰间的距离，单位 Hz
  • J 与外加磁场强度无关（δ 也是相对值；真正随场强变的是 Δν/J）

① 四步法（照这个顺序数）

第 1 步有没有σ 键？有 → σ→σ*（几乎必答，但常在远紫外）

第 3 步有没有不饱和键（C=C、C=O、C=N）？有 → π→π*

第 4 步核对是否共轭 / 是否有苯环 → 决定吸收带的名称与位置

紫外部分（1–9）

1为什么 UV 是带状（连续）光谱？
电子跃迁必然伴随振动、转动能级变化，大量密集子能级叠加 → 呈带状。
2为什么 π→π* 的 ε 远大于 n→π*？
π→π* 是允许跃迁、靶面积大；n→π* 是禁阻跃迁（n 与 π* 空间重叠差），跃迁概率小。
3为什么共轭多烯双键越多 λ 越长？
共轭形成新轨道组，HOMO–LUMO 能差减小 → 跃迁能量下降 → 波长变长。
4为什么助色团使 π→π* 红移、却使 n→π* 蓝移？
① 助色团推电子共轭使 π* 降低 → π→π* 红移；
② 同时孤对参与共轭后 n 轨道能量被抬高，n→π* 的 ΔE 变大 → 蓝移。
（这是课后题第 6 题的标准答法，"轨道一升一降"是关键）
5为什么极性溶剂使 n→π* 蓝移、π→π* 红移？
n→π*：极性溶剂与基态形成氢键，基态降得多 → ΔE↑ → 蓝移；
π→π*：与激发态 π* 作用更强，激发态降得多 → ΔE↓ → 红移。
6为什么苯胺在酸中蓝移、苯酚在碱中红移？
苯胺成 -NH₃⁺ → 孤对消失、p-π 共轭破坏 → 回到近苯位置（蓝移）；
苯酚成 -O⁻ → 孤对更易给电子、共轭增强 → 红移。
7为什么苯的 B 带在极性溶剂中精细结构消失？
极性溶剂溶剂化/缔合把振转能级"抹平"，精细结构并成宽单峰。
8为什么饱和烃可作 UV 溶剂？
只有 σ→σ*，吸收在 <150 nm，200–400 nm 全透明。
9为什么稠环线型红移、角式蓝移？
线型（萘、蒽）共轭体系更大、更"直"→ 红移、强度大；角式（菲）共轭路径弯折 → 强度弱、λ 小。

红外部分（10–18）

10为什么 CO₂ 有 4 个振动却只有 2 个峰？
对称伸缩 Δμ = 0（红外非活性）；两个弯曲振动简并。
11为什么 H₂、O₂、Cl₂ 无红外吸收？
同核双原子分子伸缩时偶极矩恒为 0。
12为什么键越强、波数越高？
ṽ = 1307√(k/μ′)，k↑ → ṽ↑：νC≡C > νC=C > νC-C。
13为什么 O-H、N-H、C-H 都在 3000 以上？
与 H 相连 → 折合质量 μ′ 极小 → 波数高。
14为什么弯曲振动波数低于伸缩？
弯曲的力常数小，容易发生 → ν伸缩 > δ弯曲。
15为什么氢键使 IR 频率降低、却使 NMR 的 δ 增大？
IR：氢键削弱 X-H 键强 → 力常数↓ → 频率↓（同时偶极矩变化↑ → 峰增强变宽）；
NMR：氢键把氢拉向电负性原子 → 电子云密度↓ → 去屏蔽 → δ↑。
16为什么羧酸 νC=O 比酮低？
羧基的 +C 共轭（O 孤对给电子）作用大于其诱导效应。
17为什么酰氯 νC=O 高达 1800？
Cl 的强吸电子诱导使 C=O 电子云密度↓、力常数↑。
18为什么五元内酯 νC=O 高于六元？
环张力使键角偏离理想值，C=O 键强增加 → 频率↑。

注意与"叔丁基 1390/1365"区分 —— 后者是振动偶合
20为什么 -C(CH₃)₃ 出现 1390/1365 双峰？
两个甲基的对称面内弯曲振动振动偶合而分裂（1365 强度约为 1390 的 2 倍）。
21为什么炔氢的 δ 反而最小（1.8–3.0）？
三键的磁各向异性使炔氢处于正屏蔽区（沿键轴方向感应磁场与外场同向叠加在核外）。
不是电负性原因 —— 若按 sp 杂化推会得到错误顺序
22为什么反式烯氢的 J 大于顺式？
Karplus：J = 4.2 − 0.5cosφ + 4.5cos2φ，反式两面角≈180° → J 最大（12–18 Hz）。
23为什么 J 与磁场强度无关？
J 源于成键电子传递的自旋偶合，是分子本征性质；而 Δν 与场强成正比 → 所以高场仪器 Δν/J 变大，谱图更接近一级。
24为什么选 TMS 作基准？
① 12 个 H 化学环境完全相同 → 单峰不干扰
② Si 电负性小于 C → 屏蔽最强 → 出现在最高场，δ=0
③ 惰性、易溶、易挥发（bp 26.5 ℃，样品可回收）
25为什么 B 带的 ε 只有 ~220？
苯的 π→π* 在自由分子中属对称性禁阻（跃迁概率小）；但被取代后对称性破坏、共轭延长，ε 可升到 10⁴。
26为什么 ¹³C-NMR 要 10 mg 以上、且常需累加？
¹³C 天然丰度仅 1.107%，且 γ 只有 ¹H 的 1/4 → 灵敏度低 → 靠脉冲累加（PFT）提高信噪比。
27为什么酸性氢（-OH、-COOH）峰又宽又矮？
① 存在氢键缔合，缔合程度随浓度/温度变化 → 峰位漂移、变宽
② 存在快速交换 → 与邻近质子偶合被平均掉 → 不裂分、呈宽峰
28为什么加 D₂O 后活泼氢峰消失？
活泼氢与 D 发生化学交换（ROH + D₂O → ROD + HOD），生成 ROD 后在 ¹H 谱中不再出峰。

① 随堂投票题（PPT 原题，命中率最高）

1HPLC-UV 检测槲皮素、槲皮素-3-O-葡萄糖苷、人参皂苷 Rg3 的混合物，用 280 nm 检测出现几个峰？

2四氯化碳在 ¹H-NMR 中出现几个信号？
A 1　B 2　C 3　D 没有
答：D。CCl₄ 不含氢，¹H 谱无信号（它本身是常用溶剂）。
3下列氢谱描述正确的是
A δ 越大越在高磁场　B δ 越大越在低磁场
C δ 越大去屏蔽效应越大　D δ 越大屏蔽效应越大
答：B、C（两句话其实是同一件事：δ 大 = 低场 = 去屏蔽强）。若为单选，选"去屏蔽越大"这条机理表述。
4I = 1/2 的核，下列说法正确的是
A 热平衡时 +1/2 核稍少　B 两能级核数相等时不再吸收能量（这是"饱和"，不是题干的"正确说法"）
C +1/2 比 −1/2 多这种现象叫饱和　D 比热平衡多的 −1/2 核释放能量回到 +1/2 直到恢复 Boltzmann 分布，叫弛豫
答：D（弛豫的定义）。注意 B 描述的是"饱和"的定义，本身正确但与该题"弛豫"语境不符时按 D。
5CO₂ 有几种基本振动？红外谱图出现几个吸收峰？
答：振动 4 个（3N−5=4），峰 2 个（对称伸缩非活性 + 弯曲简并）。
6甲醛（CH₂O）有几种基本振动？应出现几个吸收峰？
答：振动 6 个（3N−6 = 3×4−6 = 6：νs(CH₂)、νas(CH₂)、δ 剪式、ρ 面内摇摆、ω 面外摇摆、ν(C=O)）。

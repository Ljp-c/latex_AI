③ 波谱分析的定义

波谱解析：应用紫外光谱（UV）、红外光谱（IR）、核磁共振光谱（NMR）和质谱（MS）等现代物理手段研究物质微观结构的一门学科。

④ 电磁辐射的基本性质

电磁辐射：以接近光速（真空中为 c）沿波前进方向传播的交变电场 E 和磁场 B，可对带电粒子、电和磁偶极子施加电力、磁力。
  • 具有波动性和微粒性 → 即波粒二象性
  • 光是高速通过空间传播的光子流
  • 光子能量：E = hν = hc/λ
  • 四个参量：波长 λ、频率 ν、波数 ṽ、能量 E
ΔE = hν = hc/λ　　ṽ = 1/λ = ν/c

① 分子轨道的形成

原子轨道线性组合：两个原子轨道线性组合形成两个分子轨道。
类型重叠方式能量
成键轨道波函数位相相同（同号）低于组成它的原子轨道
反键轨道 Ψ*波函数位相相反（异号）高于组成它的原子轨道
  • 原子轨道相互作用越大，形成的分子轨道越稳定
  • 有机化学中构成化学键的原子轨道有 s、p 轨道及各种杂化轨道
  • 原子轨道用波函数 Φ 表示；分子轨道用波函数 Ψ 表示

② 三类分子轨道（核心定义）

轨道形成方式分布特点
σ 轨道两个 p 轨道"头对头"
（σp、σp*）		围绕键轴作对称分布
π 轨道两个 p 轨道"肩并肩"
（πp、πp*）		围绕键轴非对称分布
n 轨道原子上未用电子对（孤对电子）非成键轨道，没有反键轨道
n 轨道：在分子轨道中，未与另一原子轨道相互作用的原子轨道（即未用电子对），其在分子轨道能级图上的能量等同于其在原子轨道中的能量，称非成键（nonbonding）分子轨道，亦称 n 轨道；n 轨道上的电子称 n 电子。
必考点：n 轨道是非成键的，所以没有反键轨道（写成 n* 是错的）。

③ 基态与电子跃迁

基态电子排布在 n 轨道以下的轨道上
电子跃迁基态的一个电子被激发到反键分子轨道（电子激发态）
能量尺度相邻能级的能量差 ≈ 1–20 eV（1 eV = 1.6×10−19 J），与紫外和可见光的能量相当
必要条件只有照射光的能量与价键电子的跃迁能相等时，光才能被吸收；

🔴 逐条必背（选择题原型）

σ→σ*σ 键较为牢固，跃迁需能量最大，吸收波长最短，在远紫外区。
饱和烃只含 σ 键 → 只能 σ→σ*，峰 <150 nm，在 200–400 nm 无吸收，在一般仪器测定范围之外 → 常作溶剂（甲烷 125、乙烷 135）
π→π*能量小于 σ→σ*。孤立 π→π* 在 200 nm 附近，特征：吸收强度大（ε>104）。
有 C=C、C≡C、C=N 的化合物（不饱和烃、共轭烯烃、芳香烃）都产生。
共轭使所需能量降低、λmax 增加至 >210 nm（乙烯 165 → 丁二烯 217）
n→π*含杂原子的不饱和基团（C=O、C=S、N=N），未成键轨道中的孤对电子向 π* 跃迁。
所需能量最小，在近紫外甚至可见区；跃迁选律上属禁阻跃迁，特征：吸收强度弱（ε 在 10～100）。
丙酮 λmax=279 nm，ε 10–30
n→σ*含 -OH、-NH2、-X、-S 等含杂原子的饱和化合物：除 σ 电子外还有未成键的 n 电子，孤对向 σ* 跃迁。所需能量比 σ→σ* 小，λ 一般 <200 nm 的真空紫外区，通常为末端吸收
结论：只有 π→π* 与 n→π* 两种跃迁能量小、相应波长出现在近紫外甚至可见光区，且对光的吸收强烈，是研究的重点。

① 发色团（生色团，chromophore）

定义：分子中决定电子吸收带波长和强度的原子团及其相关的化学键。
  • 最有用的紫外—可见光谱由 π→π* 和 n→π* 跃迁产生
  • 吸收波长大于 210 nm，如 -C=C-、-C=O、-NO2 等
  • 紫外光谱只适用于分子中具有不饱和结构的化合物；饱和烷烃和环烷烃在 200–400 nm 无吸收

② 助色团（auxochrome）

⑥ Lambert-Beer 定律（定量依据）

物理意义：物质吸收光子量的多少不仅取决于物质的分子结构，而且还和被光子作用的物质的分子数目（即浓度）有关——这就是吸收光谱法定量的依据。
溶液的浓度越大、液层的厚度越大 → 光强度减弱越显著
It = I0 × 10−KLC　　It/I0 = 10−KLC　　A = KLC

（三）共轭效应（红移的根本原因）

机理：共轭双键中，每个双键的 π 轨道相互作用，发色团的能级变得相对较近，即形成一套新的成键和反键轨道。从 HOMO 向 LUMO 跃迁所需能量下降 → 吸收峰向长波长移动。

① 红外光谱的本质

IR：由分子振动-转动能级跃迁引起，故称为分子的振动-转动光谱。
指纹性有共价键的化合物（包括有机物和无机物）都有其特征的红外光谱
唯一性除光学异构体及长链烷烃同系物外，几乎没有两种化合物具有相同的红外吸收光谱

三个特点

1特征性强，可用于定性分析和结构鉴定
2应用范围广：气体、液体到固体；无机物到有机物；高分子到低分子
3分析速度快，样品用量少，不破坏样品
紫外光谱红外光谱
基于电子能级跃迁，主要提供共轭体系的信息基于振动、转动能级跃迁，主要提供官能团的信息

② 红外吸收的两个必要条件（最核心）

条件一
能量匹配		照射光能量等于两个振动能级的能量差：UL = ΔE = hν。
分子振动能级是量子化的，只有当红外光的频率恰好等于分子某一振动方式的固有频率时，分子才能吸收能量，从基态跃迁到激发态。
条件二
偶极矩变化		分子振动时，其偶极矩必须发生变化（Δμ ≠ 0）。
偶极矩：表示分子中电荷分布情况的物理量，它是正、负电荷中心间的距离和电荷中心所带电量的乘积。
红外活性振动分子振动产生偶极矩的变化，从而产生红外吸收的振动
非红外活性振动分子振动不产生偶极矩的变化，不产生红外吸收的振动

① NMR 的定义

核磁共振（Nuclear Magnetic Resonance，NMR）：将磁性原子核放入强磁场后，用适宜频率的电磁波照射，它们会吸收能量，发生原子核能级跃迁，同时产生核磁共振信号，从而我们能观察到原子核的磁共振现象。

应用：有机化学、生物化学、药物化学、物理化学、无机化学，医药、生物、物理等领域必不可少的研究手段；MRI 依赖人体水中的氢原子（人体约 70% 是水）。

⑩ 屏蔽效应（NMR 的"化学位移"基础）

定义：核外电子产生与外加磁场相对抗的第二磁场，增加了一个免受外加磁场影响的防御措施，这种作用叫作电子的屏蔽效应。

CH4核电子屏蔽效应较大
CH3OH核电子屏蔽效应较小
HN = H0 − σH0　　ΔE = 2μH0(1 − σ)
结论屏蔽效应越强 → 核跃迁能越小；当 σ=0（无电子屏蔽）时 ΔE = 2μH0
共振条件2μH0(1−σ) = hν → H0 = hν/[2μ(1−σ)]

① 自旋偶合与裂分（定义）

自旋-自旋偶合：相邻原子核自旋产生磁场的相互作用，通过成键电子传递相互干扰。
自旋-自旋裂分：由自旋偶合作用引起的共振吸收峰分裂成多个峰的现象。
偶合常数 J：裂分后两个小峰间的距离，单位 Hz。
J 与外加磁场强度无关是代表自旋核之间相互作用的常数
相互偶合的两组峰峰间距离相等，即偶合常数相等（JHa,Hb = JHb,Ha）
峰面积有干扰时两小峰面积/强度相等（1:1）；无 F 干扰时的峰面积 = 有干扰时两峰面积之和

① AB 系统四峰公式（高级偶合，可能考计算）

前提：AB 系统给出 4 个峰，按频率由高到低记为 v1 > v2 > v3 > v4。判据：Δν/J ≤ 6 → 高级偶合（AB）；Δν/J > 6 → 一级谱（AX）。

强度比I2/I1 = I3/I4 = (v1 − v4)/(v2 − v3)
δAδA = v1 − [(v1 − v4) − ΔνAB]/2
δBδB = δA − ΔδAB

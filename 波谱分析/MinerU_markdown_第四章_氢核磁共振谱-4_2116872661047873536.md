## 一、1H-NMR谱解析的基本程序

1. TMS等信号是否正常，底线是否平坦，溶剂信号出现预定位置，S/N是否符合要求（一般>30）。

2. 算H数 $( \delta < 4 . 5$ 的区域先找出，如- $- { \cal O } { \cal C } \mathsf { H } _ { 3 \cdot \mathrm {  ~ \nabla ~ } } - \mathsf { A r } - { \cal C } \mathsf { H } _ { 3 \cdot \mathrm {  ~ \nabla ~ } } - { \cal C } { \cal O } -$ $C H _ { 3 } , - C C H _ { 3 }$ 等孤立 ${ \mathsf { C H } } _ { 3 }$ 信号）。

3. 滴加 ${ \pmb { \mathrm { D } } } _ { 2 } { \pmb { 0 } }$ ，解析活泼氢。

10-16低磁场区域出现的-COOH及具有分子内氢键缔合的-OH信号等。

5. 参考化学位移、峰裂分数目及偶合常数，解析低级偶合系统。

6. 解析芳香氢核信号及高级偶合系统。

7. 必要时，可以更换溶剂、加入位移试剂或采用去偶试验、NOE测定，或改用强磁场NMR仪。

8. 对推测出的结构再利用取代基位移加和规律，或结合化学方法，或UV、IR、MS、<sup>13</sup>C-NMR等进行反复推敲加以确定，并对信号的归属一一作出确认。

已知化合物的图谱解析比较容易，应参照标准图谱或文献数据进行结构确定。

# ① 纲领清单（逐条打勾）

## 第一章 绪论（6 条）

- [ ] 1-1 能说出波谱解析的定义（UV/IR/NMR/MS 研究**微观结构**）
- [ ] 1-2 记住 ΔE = hν = hc/λ；能级大小：**Ee ≫ Ev > Er**；**振动光谱涵盖转动光谱**
- [ ] 1-3 默出「波段—跃迁—技术」对应：UV↔电子、IR↔振动-转动、射频↔核自旋、MS↔m/z（**非吸收**）
- [ ] 1-4 默出四大谱对照表：激发光 / 探测信息 / 解决的结构问题 / 样品量 / 能否回收
- [ ] 1-5 说出波谱法五大优点（**不含**"不需纯样品"）；样品纯度 **95% 以上**
- [ ] 1-6 说出黄酮带 I（300–400，B 环桂皮酰基）/ 带 II（200–300，A 环苯甲酰基）及三类强度规律

## 第二章 紫外光谱（16 条）

- [ ] 2-1 说出 UV 的产生（价键电子基态→激发态），能量差 **1–20 eV**
- [ ] 2-2 分辨 σ / π / n 轨道；**n 轨道是非成键轨道，无反键轨道**
- [ ] 2-3 默出四种跃迁的**吸收区域 + 强度 + 典型值**（CH₄ 125、CH₃Cl 173、乙烯 165、丁二烯 217、丙酮 279）
- [ ] 2-4 默出能量次序：**σ→σ\* > n→σ\* > π→π\* > n→π\***
- [ ] 2-5 定义发色团、助色团；能判断谁是发色团（-NO₂）、谁是助色团（-OH、-NH₂、-OR、-X）
- [ ] 2-6 定义红移/蓝移/增色/减色，并能给原因
- [ ] 2-7 **默出 R/K/B/E 四带表**（跃迁、波长、ε、名称来源）
- [ ] 2-8 说出 B 带精细结构：非极性溶剂有、极性溶剂消失
- [ ] 2-9 写出 Lambert-Beer 的三种表达 + 加和性；会用 **A = 2 − lg(T%)**
- [ ] 2-10 说出 ε 的物理意义（1 mol/L、1 cm 时的 A）与强度分级（>10⁴ 很强）
- [ ] 2-11 复述六大影响因素框架（跃迁类型 / 发色团助色团 / 共轭 / 溶剂 / 立体 / 强度）
- [ ] 2-12 **记住溶剂效应方向**：n→π\* 蓝移、π→π\* 红移；记住水/甲醇/乙醇/氯仿/丙酮/二硫化碳的极限波长
- [ ] 2-13 说出 pH 效应：碱→红移（酚羟基/烯醇/不饱和酸）、酸→蓝移（芳胺）
- [ ] 2-14 **会用 Woodward-Fieser**（二烯：217 基值）与**共轭羰基规则**（207/215/215/202/193 母体值），会做溶剂校正
- [ ] 2-15 会用 **Fieser-Kuhn**（>4 个共轭双键）
- [ ] 2-16 说出芳香族规律 + 六条经验规律 + 黄酮四种诊断试剂 + 构型构象/互变异构/纳米 SPR

## 第三章 红外光谱（18 条）

- [ ] 3-1 说出 IR 的本质（振动-转动跃迁）与"指纹性"（除光学异构体、长链烷烃同系物外不重复）
- [ ] 3-2 **默出两个必要条件**：能量匹配 + **Δμ≠0**
- [ ] 3-3 举出非红外活性的例子（H₂/O₂/Cl₂、CO₂ 对称伸缩）
- [ ] 3-4 默出三区域：近红外 12820–4000、中红外 **4000–400**、远红外 400–33
- [ ] 3-5 说出横坐标是波数（**越大能量越高**）、纵坐标 T%/A、**A = lg(1/T)**
- [ ] 3-6 会算 $\tilde\nu = 1307\sqrt{k/\mu'}$，记住 C–C 1190、C=C 1690、C≡C 2060
- [ ] 3-7 **说出四条规律**：键强↑频率↑、原子重↑频率↓、连 H 高波数、弯曲低于伸缩
- [ ] 3-8 分清基频峰（强，峰位=振动频率）与泛频峰（倍频+合频+差频，弱）
- [ ] 3-9 **会画振动分类树**：伸缩(νs/νas) + 弯曲(面内 β：剪式 δ/摇摆 ρ；面外 γ：摇摆 ω/扭曲 τ)
- [ ] 3-10 记住 -CH₂- 剪式 ~1465、面内摇摆 ~720、δs(CH₃) 1380、δas(CH₃) 1460
- [ ] 3-11 **会说自由度**：线性 3N−5、非线性 3N−6；水 F=3、CO₂ F=4
- [ ] 3-12 **背出"峰数少于自由度的 5 个原因"**
- [ ] 3-13 说出影响峰位的内部 7 因素 + 外部 3 因素
- [ ] 3-14 说清诱导效应（频率↑）与共轭效应（频率↓）的方向；诱导>共轭 → 1735；共轭>诱导 → 1689
- [ ] 3-15 说清氢键（频率↓、强度↑、变宽）与游离/缔合 O-H 的数值（3640 尖 / 3300 宽）
- [ ] 3-16 分清**振动偶合**（1390/1365、伯胺双峰、酸酐双峰）与**费米共振**（醛 2820/2720）
- [ ] 3-17 **背出特征区 4000–1300 / 指纹区 1300–400**，说出相关峰与羧基的 5 种相关峰
- [ ] 3-18 会算不饱和度，会按"先官能团区后指纹区、先强后弱、找相关峰、排除水和 CO₂"解析

## 第四章 氢核磁共振谱（18 条）

- [ ] 4-1 说出 NMR 三大参数分别回答什么问题（δ→环境、J→邻居、积分→个数）
- [ ] 4-2 **用 I 判断能否 NMR**：偶数/偶数 → I=0 → 无信号（¹²C、¹⁶O、³²S）；奇数 → 半整数（¹H、¹³C、¹⁹F、³¹P）
- [ ] 4-3 说出 I=1/2 的核最适合 NMR 的原因（球形、谱线窄）
- [ ] 4-4 写出 μ = γP、P = √(I(I+1))·h/2π；记住 γ(¹H) ≈ 4γ(¹³C)
- [ ] 4-5 **自旋取向数 = 2I + 1**；¹H 为 2
- [ ] 4-6 写出 **ΔE = 2μH₀**（有屏蔽：2μH₀(1−σ)）；写出共振条件 ν = (2μ/h)H₀
- [ ] 4-7 说清 Boltzmann 分布、**饱和**、**弛豫**；分清 T₁（自旋-晶格，能量下降）与 T₂（自旋-自旋，能量不变）
- [ ] 4-8 说出扫频 / 扫场的区别；记住 1.4092 T ↔ ¹H 60 MHz、2.35 T ↔ 100 MHz
- [ ] 4-9 说清屏蔽效应与 δ 的对应：**屏蔽强 → δ 小 → 高场**
- [ ] 4-10 写出 δ 的计算式；说出 TMS 三条优点与 DSS（水溶性）、HMDS
- [ ] 4-11 **背出影响 δ 的五大因素**，并会用 CH₃X 系列判断 δ 大小
- [ ] 4-12 **会用磁各向异性解释**：苯环 6.0–9.0（负屏蔽）、双键 4.5–5.7（负屏蔽）、炔氢 1.8–3.0（正屏蔽）
- [ ] 4-13 说出氢核交换次序 -OH > -NH₂ > -SH；会用 D₂O 判断活泼氢
- [ ] 4-14 说出氢键对 δ 的影响（δ↑）及浓度/溶剂/温度的作用方向；分清分子内与分子间氢键
- [ ] 4-15 **背出 δ 分区**：烷基 0.9–1.65、连氧 3.3–4.0、炔 1.8–3.0、烯 4.5–5.7、芳 6.0–9.0、醛 9–10、羧酸 10–13
- [ ] 4-16 **会用 n+1 与 Pascal 三角**；会算 J = Δδ × 仪器兆数
- [ ] 4-17 说出偕偶/邻偶/远程偶合的特征值（ax-ax 6–14、ax-eq 0–5、反式烯 12–18、顺式烯 6–12、芳环邻 6–10）
- [ ] 4-18 分清化学等同/磁等同、低级(Δν/J>6)/高级偶合；记住 AB 系统四峰公式；说出 NOE ∝ 1/r⁶ 与位移试剂

# ⑥ 解题流程卡

## A. 算 UV 的 λ<sub>max</sub>（共轭体系）

```
1. 判断共轭双键数 n
   n ≤ 4  → Woodward-Fieser（二烯规则）
   n > 4  → Fieser-Kuhn
2. 若母体是 C=O → 用"共轭羰基规则"（207/215/202/193）
3. 逐条累加：同环/环外/烷基/助色团
4. 若在非极性溶剂测 → 加溶剂校正（己烷/环己烷 +11，水 −8）
5. 与实测值比对，选最接近的候选结构
```

**易漏项自查**：环外双键全算了吗？环上羰基有没有误当环外双键？交叉共轭是否只取一个？

## B. 红外谱图解析

```
1. 算不饱和度 Ω（由分子式）
2. 3000 cm⁻¹ 分界：以上有峰 → 不饱和 C-H（=C-H/≡C-H/Ar-H）；只在以下 → 饱和
3. 逐个高波数峰定性：
   3300 尖 → ≡C-H ；3500–3200 宽 → O-H ；3490/3400 双峰 → 伯胺 N-H ；~3030 → Ar-H
4. 1900–1650 有强峰 → 羰基 → 按 1810/1800/1760/1735/1725/1715/1710/1690 定类型
5. 1680–1500：1600/1500 四重峰 → 芳环；单独弱尖 1690–1620 → C=C
6. 2260–2215 尖 → C≡N ；1600–1500 + 1390–1300 双强峰 → -NO₂
7. 1000–650 γ 峰定取代类型；900–690 强 → 芳环取代
8. 找相关峰佐证（C=O 须有 C-O；O-H 须有 C-O-H）
9. 排除水（~3400、1640）与 CO₂（~2350）
```

## C. ¹H-NMR 谱图解析

```
1. 数"几组峰" → 几类化学环境不同的氢
2. 读积分高度比 → 各类氢的相对个数（结合分子式的 H 总数定绝对值）
3. 读 δ → 定氢的类型（用表卡 11）
4. 读裂分（n+1）→ 定邻接碳上的氢数
5. 量 J → 定构型/构象（ax-ax 大、反式烯大）
6. 用 D₂O 交换确认活泼氢（峰消失）
7. 检查有无溶剂峰（CDCl₃ 7.3、DMSO 2.5、D₂O 4.7、CD₃OD 3.3/4.8）
```

## D. 综合定结构（四谱联用）

```
分子式 → Ω → IR 定官能团 → NMR 定氢的分布与邻接 → UV 校验共轭 → 拼结构 → 逐条自检
```

**自检清单**：① 所有 H 都分配了吗 ② 每个官能团都有对应峰吗 ③ Ω 与结构一致吗 ④ 裂分关系与连接顺序自洽吗 ⑤ 有没有把活泼氢的宽峰误当成烷基

## 3. 饱和 (saturation)与驰豫 (relaxation)

• 当+1/2能级的核与-1/2能级的核数相等时，不再吸收能量。这种状态叫饱和。

• 比热稳定状态多的-1/2能级的核又通过释放能量回到+1/2能级，直至恢复到Boltzmann分布的热平衡状态，这种现象叫驰豫。

## 驰豫 (relaxation)

## T1（自旋-晶格驰豫

处于高能态的核自旋体系与其周围的环境之间的能量交换过程，其结果是部分核由高能态回到低能态，核的整体能量下降。

• 自旋-晶格驰豫时间T1越小，表明驰豫过程的效率越高，大小与核的种类、样品状态、温度有关。气体、液体样品T1一般10<sup>-4</sup>-10<sup>-2</sup>秒。

## T2（自旋-自旋弛豫）

• 高能态的自旋核把能量转移给同类的低能态核，同时低能态的核获得能量跃迁到高能态的过程。其结果核的整体能量不改变。

• 对固体或黏稠液体，核之间的相对位置较固定，利于核间能量传递转移，T2较短，约10<sup>-3</sup>秒，非黏稠液体T2较长，约1秒。

核磁矩的拉莫尔进动

## 4. 核的进动与拉莫尔频率 (Larmor frequency)

核跃迁与电子屏蔽效应


• 自旋量子数I =1/2的核在外磁场中在有屏蔽效应时两个能级间的能级差 $\Delta E = 2 \mu H _ { \mathrm { { N } } }$ 

$$
H _ {N} = H _ {0} - \sigma H _ {0} \quad \Delta E = 2 \mu H _ {0} (1 - \sigma)
$$

∴ 屏蔽效应越强，核跃迁能越小。当 ${ \pmb { \sigma } } \mathrm { = } { \pmb { 0 } }$ 即无电子屏蔽效应时， $\Delta E = 2 \mu H _ { 0 }$ 

$\Delta E = 2 \mu H _ { 0 } ( 1 - \sigma )$ ∵ 发生NMR时，核跃迁能 $\ : \pmb { \Delta } \pmb { E } = \ :$ 照射用电磁辐射能 $( \Delta E ^ { \cdot } )$ 

$$
\therefore 2 \mu H _ {0} (1 - \sigma) = h v \quad H _ {0} = \left. h v \right/ [ 2 \mu (1 - \sigma) ]
$$

在有机化合物分子中，即使是同类型的核，每个核也因所处的化学环境不同，而所受电子屏蔽效应强弱不同（ σ值大小不同）。因此，即使在同一频率的电磁辐射照射下同类型的不同核也因所处的化学环境不同而在强度稍有差异的不同磁场区域给出共振信号，从而提供有用的结构信息。

## • n轨道——原子上未用电子对形成的分子轨道

– 在分子轨道中，未与另一原子轨道相互作用的原子轨道（即未用电子对）其在分子轨道能级图上的能量大小等同于其在原子轨道中的能量，这种类型的分子轨道称为非成键 (nonbonding) 分子轨道，亦称n轨道。n轨道上的电子称n电子。

– n轨道是非成键的分子轨道，所以没有反键轨道。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-10-26/1081f8da-0433-49a6-b8e2-71755a7d0691/a5e8f4f5f1589a3c0d119888645a336ec65ca04904f148d30d8566c74edadc99.jpg)



分子轨道电子跃迁能级图


基态的一个电子被激发到反键分子轨道（电子激发态），称为电子跃迁

相邻能级的能量差≈1-20 eV (1 eV = 1.6 x 10<sup>-19</sup> J)，与紫外和可见光的能量相当

电子排布在n轨道以下的轨道上，这种状态称基态

$$
\text { 物质 } \xrightarrow [ \text { 必要条件 } ]{\text { 紫外光or可见光 }} \text { 电子跃迁 }
$$

• 只有当照射光的能量与价键电子的跃迁能相等时，光才能被吸收。

• 光的吸收与化学键的类型有关。

跃迁需要能量，能量来源于特定波长的光

$$
\text { 物质 } \xrightarrow [ \text { 必要条件 } ]{\text { 紫外光or可见光 }} \text { 电子跃迁 }
$$

## 1. 发色团(chromophore，生色团)

– 最有用的紫外—可见光谱是由π→π*和n→π*跃迁产生的。 吸收波长大于210 nm，如-C=C-，-C=O，-NO 等。分子中决定电子吸收带波长和强度的原子团及其相关的化学键被称为发色团。

– 紫外光谱只使用于分子中具有不饱和结构的化合物的分析， 饱和烷烃和环烷烃在200-400 nm没有吸收。

## 2. 助色团 (auxochrome)

– 本身不能吸收波长大于200 nm的辐射，但与发色团相连时，会发生n-π共轭作用，可使发色团所产生的吸收峰向长波长方向移动并使吸收强度增加的原子或原子团。如－OH、－NH ，—NHR 、－OR、－SH、－X等。

## 3. 红移 (red shift)

– 由于助色团的引入或溶剂效应使 $\lambda _ { \operatorname* { m a x } } |$ 向长波方向位移的效应。或称深色移动(bathochromic shift) 。

– 如发生共轭作用，引入助色团等。

## 4. 蓝移 (blue shift)

– 由于共轭效应消失或溶剂效应使向短波方向位移的效应，或称浅色移动 (hypsochromic shift)。

– 如苯胺在酸性介质中。

## 7. 吸收带

– 是指与结构相对应的峰形及峰位，可获得结构信息，用于推断化合物的结构。

通常可分为4类：

R带、K带、B带、E带

## • R带

n→π*跃迁所产生的吸收带。以德文Radikal（基团）得名，是含有杂原子的不饱和基团（如- $\cdot C = O , \cdot N = O , \cdot N O _ { 2 } ,$ N=N-等发色基团）的n→π*跃迁所产生。

• 特点：

处于较长波长范围（250-500 nm），吸收强度很弱，ε < 100。

## K带

共轭双键的π→π*跃迁所产生的吸收带。

从德文Konjugierte（共轭作用）得名，它的吸收峰出现区域为210-250 nm，吸收强度大， ε >10000 (lgε > 4)。

## 8. Lambert-Beer定律

Incident Beam (I ) 

Absorption of light by molecules 

Emergent Beam (I<sub>T</sub>) with lower intensity 

透射光强度减弱

物质吸收光子量的多少不仅取决于物质的分子结构，而且还和被光子所作用的物质的分子数目有关（即与物质浓度有关），这就是吸收光谱法定量的依据。

## Lambert-Beer定律

– 当一束单色光通过溶液时，由于溶液吸收了一部分光能，光的强度就要降低。溶液的浓度越大，液层的厚度越大，光强度的减弱也越显著。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-10-26/1081f8da-0433-49a6-b8e2-71755a7d0691/a5dba718a83ac6e2fe9305084e30b9251d59e3c880c73f4b2a74e87e0981fda4.jpg)


$$
I _ {t} = I _ {0} \times 1 0 ^ {- K L C}
$$

$I _ { 0 }$ :入射光强度； $I _ { t } \colon$ :透射光强度；�:溶液浓度

透光率(transmittance)

�:液层厚度； $\pmb { K } \left( \mathbf { o r } \pmb { \alpha } \right)$ :比例常数（吸收系数）

$$
\frac {I _ {t}}{I _ {0}} = 1 0 ^ {- K L C}
$$

## Lambert-Beer定律

– 百分透光率1 (T %)： $I _ { \mathrm { f } } / I _ { 0 }$ 数值小于1

吸收度 (absorbance, A)：透光率的负对数值 (-lgT) 表示溶液吸收光的程度。过去称消光度 (extinction, E)或光密度 (optical density, OD)。

$$
\begin{array}{l} A = - \lg T = \lg \frac {1}{T} = 2 - \lg (T \%) \\ \left. \begin{array}{l} A = K L C \\ I _ {t} = I _ {0} \times 1 0 ^ {- K L C} \\ \frac {I _ {t}}{I _ {0}} = 1 0 ^ {- K L C} \end{array} \right\} \text { Lambert - Beer定律的不同表达形式，这一定律又称Bouger - Beer定律 } \end{array}
$$

Lambert-Beer定律

![image](https://cdn-mineru.openxlab.org.cn/result/2026-10-26/1081f8da-0433-49a6-b8e2-71755a7d0691/3b1636f1611ff49929a46da2f3ad7fc0ef2da07c17fbe608a07c02def758aad2.jpg)


– 吸收度有加和性，在溶液中如有浓度为 $C _ { \mathsf { a } }$ 的a物质和浓度为 $C _ { \mathrm { b } }$ 的b物质时，测得的溶液的吸收度 (A)为两物质的吸收度 $\underline { { A } } _ { a s }$ 、 $\underline { { \pmb { A } } } _ { \bf b } .$ 之和。

$$
A = A _ {a} + A _ {b} = K _ {a} L _ {a} C _ {a} + K _ {b} L _ {b} C _ {b}
$$

## • 跃迁概率

– 原子和分子与电磁波相互作用，从一个能量状态跃迁到另一个能量状态要服从一定的规律，这些规律称作为光谱选律。

## “允许跃迁”

两个能级之间的跃迁根据选律是可能的，其跃迁几率大，吸收强度大。

## “禁阻跃迁”

两个能级之间的跃迁根据选律是不可能的，其跃迁几率小，吸收强度很弱甚至观察不到吸收信号。

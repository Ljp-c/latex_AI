## （二）Fieser-Kuhn公式

• 超过四烯以上的共轭多烯体系，其K带的 $\pmb { \lambda _ { \mathrm { m a x } } }$ 和 $\lvert \varepsilon _ { \mathrm { { m a x } } } \rvert$ 值的计算应采用Fieser-Kuhn公式。化合物上取代基对 $\Pi { \longrightarrow } \Pi ^ { \star }$ 跃迁吸收带（K带）的影响。以丁二烯为基本母核，吸收波长217 nm为基值上，加校正值，计算共轭烯类化合物的K带 $\lambda _ { \operatorname* { m a x } \circ }$ 

$$
\begin{array}{l} \lambda_ {\max} = 1 1 4 + 5 M + n (4 8 - 1. 7 n) - 1 6. 5 R _ {\mathrm{endo}} + 1 0 R _ {\mathrm{exo}} \\ \varepsilon_ {\max} = 1. 7 4 \times 1 0 ^ {4} n \end{array}
$$

 M为烷基数；n为共轭双键数； $R _ { \mathrm { e n d o } }$ 为具有环内双键的环数； $R _ { \mathrm { e x o } } \mathrm { . }$ 为具有环外双键的环数。

$$
\begin{array}{l} \lambda_ {\mathrm{max}} = 1 1 4 + 5 M + n (4 8 - 1. 7 n) - 1 6. 5 R _ {\mathrm{endo}} + 1 0 R _ {\mathrm{exo}} \\ \varepsilon_ {\mathrm{max}} = 1. 7 4 \times 1 0 ^ {4} n \end{array}
$$

 M为烷基数；n为共轭双键数； $R _ { \mathrm { e n d o } }$ 为具有环内双键的环数； $h _ { \mathrm { e x } 0 } i$ 为具有环外双键的环数。

## 2. π-共轭系统的取代

• 作为发色团的取代基有π键，如 $\cdot C H = C H \cdot C = O$ 等

• 苯环与取代基的π键相互作用产生一个新的电子迁移带而使跃迁的能量降低，使 $\pmb { \lambda _ { \mathrm { m a x } } }$ 显著红移。

## 什么是波谱分析

波谱解析是应用紫外光谱 (UV)、红外光谱 (IR)、核磁共振光谱 (NMR)和质谱 (MS)等现代物理手段研究物质微观结构的一门学科。

## • 电磁辐射的基本性质

– 电磁辐射是高速通过空间传播的光子流

– 光的组成：可见光和不可见光

– 性质：光是一种电磁波，具波、粒二象性

– 光子的能量： $\mathsf { E } _ { \mathsf { L } } = h \nu = h \mathsf { c } / \lambda$

## • 波谱分析原理

一定波长的电磁波（光波），作用于被研究物质的分子，引起分子内某种物理量的改变（能级跃迁）。

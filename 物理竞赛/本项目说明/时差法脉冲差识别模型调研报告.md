# 时差法脉冲差识别模型调研报告

**所属实验：AI + 声速测量**
**主题：基于一维卷积神经网络的时差法脉冲间隔 Δt 自动识别**

---

## 摘要

时差法测量声速的关键步骤，是准确获取两路接收信号到达时刻之间的时间差 Δt。传统方法依赖人工在示波器波形上判别脉冲起跳点，既耗时又受主观经验影响。本工作把这一环节交给神经网络：以双通道原始电压波形为输入，直接自动输出 Δt。项目并行设计并训练了两种模型——**DelayNet**（端到端回归时延）与 **OnsetNet**（先定位脉冲到达时刻、再做差），并在 54 条实测记录（含 17 条人工标定）上完成了系统的消融与对比。当前首选模型在人工标定折上的交叉验证平均绝对误差达到亚微秒量级，同时保持了对全数据集输出行为的稳定可控，可作为 AI+声速测量实验的脉冲时差识别模块。

---

## 一、研究背景与任务定义

### 1.1 物理背景

在声速测量实验中，声波经介质传播后被两路接收器接收。由于传播路径长度不同，两路信号存在到达时间差 Δt。测得 Δt 后，结合两接收器间距离即可由 `v = L / Δt` 反演声速。因此，**Δt 的测量精度直接决定声速测量的精度**。

实际波形有两个特点：其一，脉冲经过换能器与介质的响应后并非理想方波，而是带有振荡拖尾的包络形状；其二，通道中除首达脉冲外还叠有多次反射回波，后随回波有时幅值反而更强。这使"哪里才是真正的到达点"成为一个需要判据的识别问题。

### 1.2 传统方法及其痛点

目前工程中常用的寻峰方法包括：

- **simple**：取绝对幅值最大点；
- **fft**：基于频谱特征的峰值定位；
- **peaks**：基于局部极大值与阈值的峰检测。

这些算法实现简单、计算快速，但存在共性困难：当后随回波强于首达波时，算法会锁定到更强的回波上，导致到达时刻系统性偏晚；不同阈值、不同时基档位下结果也不一致，需要反复调参。人工标定虽然准确，但无法批量处理，且不同操作者对起跳点的判读会不一致。

### 1.3 任务定义

本项目将问题形式化为一个**监督回归任务**：

- **输入**：双通道电压波形 `CH1 / CH2`，每个记录约 1520 个采样点，窗口时长约 700 μs，采样间隔约 0.4605 μs；
- **输出**：标量时间差 Δt；
- **目标量归一化**：为解除时基档位的影响，网络实际回归的是归一化时延 `d = Δt / T`（T 为窗口时长），推理时按 `Δt = d · T` 还原为物理时间。这样无论采样的 `dt` 如何变化，学习目标始终落在固定的相对尺度上。

一个贯穿全方案的关键判据来自数据本身：三种经典算法给出的到达位置**都晚于**人工标定，说明人工选择的是**最早到达的那次脉冲**。因此模型的学习目标被明确设定为"识别首达波"，而非"识别最强波"。

## 二、数据基础

### 2.1 数据来源与格式

数据来自 `backend/output/waveforms` 下的 `.npz` 文件。每条记录包含：

- 公共时间轴 `time_s`；
- 两通道电压 `volt_ch1` / `volt_ch2`；
- 元数据 `meta_json`；
- 可选的人工标定 `labels_json`，其中含 `delta_t`、`ch1_index`、`ch2_index`。

### 2.2 数据规模与分布

- 共 **54 条**记录，每条 `N = 1520` 点，`dt ≈ 0.4605 μs`，窗口 `T ≈ 700 μs`；
- 其中 **17 条**含人工标定，其余 **37 条**无标注；
- CH1（触发参考）的脉冲索引固定在 760 附近（t≈350 μs）；CH2 到达随后移，Δt 大致从 100 μs 增长到 184 μs 左右。

### 2.3 预处理流程

每条波形进入网络前统一做三步处理：

1. **去中位数**：消除直流偏置；
2. **幅值归一化**：按 99 分位幅值缩放，抑制个别尖峰的影响；
3. **重采样到固定长度 `L = 1024`**：使不同长度的记录具有统一的计算图尺寸。

## 三、模型设计

项目并行探索了两条技术路线，两者对"如何得到 Δt"给出了不同的归纳偏置。

### 3.1 DelayNet：端到端直接回归时延

DelayNet 把双通道波形视作二维多通道一维信号，整体送入卷积编码器，最后直接输出一个归一化时延标量。其结构组成如下：

- **主干**：多尺度一维残差卷积编码器。输入先经一个 `kernel=7、stride=2` 的 stem 卷积降采样，随后进入四个宽度递增的残差阶段（通道数 32 → 64 → 128 → 256），每阶段含两个残差块，每阶段首块做 `stride=2` 下采样；
- **残差块**：两层 `kernel=5` 卷积 + BatchNorm + GELU，配一条 1×1 卷积捷径；当输入输出通道数或步长变化时用卷积捷径对齐；
- **池化**：对最终特征图同时做全局平均池化与全局最大池化，拼接后得到 `2×256` 维特征；
- **回归头**：`Linear(512→128) → GELU → Dropout(0.2) → Linear(128→64) → GELU → Linear(64→1)`；
- **有界输出**：输出经 `scale · tanh(·)`（`scale=0.5`）映射，将预测限制在合理的时延范围内。

DelayNet 的监督信号只有 Δt 一个标量，属于"黑箱"式整体回归；它的优势是输出非常平滑、对噪声稳健。

### 3.2 OnsetNet：先定位到达时刻，再做差

OnsetNet 换了一个思路：不让网络直接回答"Δt 是多少"，而是让它回答"每条通道的脉冲在哪个位置到达"。

对每条通道，网络输出一条与时间轴对齐的**到达位置对数分布（热图）**，用 **soft-argmax** 取该分布的期望作为亚采样到达时刻：

```
p = Σ_i softmax(logit_i) · (i + 0.5) / L        # 归一化到达位置
Δt / T = p2 − p1
```

其中 `i` 为采样索引，`L` 为序列长度。由于输出是概率分布的期望而非单个离散点，模型天然具备**亚采样分辨率**——即使时间轴只有 1024 格，也能给出格点之间的连续时刻。

网络结构上与 DelayNet 共享残差设计，但做了面向定位的调整：

- stem 同为 `kernel=7、stride=2`；
- 主干四个阶段宽度为 32 → 64 → 128 → 192，每个残差块首块按需下采样，使总下采样倍率控制在 4 倍（保留足够的时间分辨率，避免定位精度损失）；
- **逐像素回归头**：`Conv1d(prev→64, k=3) → BatchNorm → GELU → Conv1d(64→2, k=1)`，输出与时间轴对齐的两通道热图；
- 热图经线性插值还原到长度 `L`，再经 softmax 归一化。

**包络门控（Envelope Gate）**：真实波形起始段只有基线噪声，若无约束，soft-argmax 可能在噪声上错误地"拾取"一个起点，造成预测伪提前。为此在推理时引入一个不参与训练的物理约束：

1. 对波形取去中位数后的绝对值，做 7 点滑动平均得到包络；
2. 取序列前 1/6 作为参考段，计算其均值与标准差，阈值取 `max(均值 + 3σ, frac · 全局峰值)`；
3. 找到包络首次**连续 12 点持续越阈**的位置，作为可信到达起点；
4. 在该起点之前将热图 logits 置为极小值（`−1e4`），使其概率归零，soft-argmax 只能在实际脉冲区域内取值。

这一步相当于用信号处理给出一个"粗定位"，再由神经网络在粗定位之后完成"精修"，二者互补。

### 3.3 集成策略

两种模型均支持多成员集成：对多个随机种子独立训练的模型输出取平均，以降低小样本下的随机波动。DelayNet 以 `EnsembleModel` 对整个网络列表求预测均值；OnsetNet 则以 `OnsetPredictor` 对多个成员的 Δt 分别推理后平均。

## 四、训练方案与数据合成

只有 17 条人工标签，直接训练深度网络远远不够。项目设计了三类数据混合训练，并配以严谨的验证协议。

### 4.1 模板重放合成

从真实记录中截取脉冲模板（主脉冲及其邻域形态），在时间轴上随机重新摆放并叠加噪声，组合成新的训练样本。它保留了真实脉冲的形态细节，能扩大样本数量与位置覆盖。

### 4.2 解析式多回波合成

模板重放只能覆盖人工段波形的形态，容易让模型把"某个特定回波"误当成目标。为此引入解析式合成器，用高斯包络正弦脉冲构造信号：

- 每个通道含 **1 个主脉冲 + 1~3 个随机回波**；
- 回波相对主脉冲延迟随机，频率、宽度、幅度均随机扰动，且幅度可能强于主脉冲；
- **标签恒为最早脉冲的起始样本**。

这样做的目的非常明确：向模型显式注入"选择最早到达脉冲"这一物理先验，而不是让模型从有限数据中自行猜测。

### 4.3 真实数据增强

对 17 条人工记录做在线增强，模拟真实测量中的波动：

- **增益扰动**：两通道分别在 0.8~1.25 倍间随机缩放；
- **噪声注入**：按前段基线噪声强度叠加高斯噪声；
- **亚采样平移**：以较高概率对 CH2 做 ±12 样本内的亚像素平移（`scipy.ndimage.shift`，线性插值），并同步修正标签位置。这一项使模型接触到非整数样本的真值，配合 soft-argmax 形成亚采样监督。

### 4.4 伪标注扩展

对 37 条无标注记录，用 simple 算法生成伪标注并按较低权重混入训练，用于扩展数据覆盖范围。实验表明，伪标注与人工的到达定义存在系统性偏移，因此项目把它作为可选的覆盖手段而非唯一监督来源。

### 4.5 损失函数

OnsetNet 采用多任务联合损失：

- **时延损失**：对 `d_pred = p2 − p1` 与真值 Δt/T 使用 Smooth L1（`beta=0.02`），在接近真值时梯度平滑、对离群点稳健；
- **热图损失**：将真值到达位置编码为高斯热图（`σ ≈ 1.5/1520`），与网络 logits 的 log-softmax 做交叉熵，逐通道计算并按掩码加权。

总损失为 `delay_weight · L_delay + onset_weight · L_onset`，默认两者权重均为 1。训练使用 AdamW（lr=1e-3，weight_decay=1e-4）、CosineAnnealingLR、梯度裁剪（max_norm=5.0），并按验证集 MAE 做早停。

### 4.6 验证协议

评估采用**按记录时间连续分折的交叉验证**（典型 5 折）：训练集为其余人工记录（可叠加合成与伪标注），验证集为留出的人工记录。同时引入第二评价维度——**全数据集行为**，检查模型是否出现"预测位置显著早于首个持续包络上升"（伪提前），以及相邻记录预测的差分是否平滑。这样避免了仅靠组内标准差而奖励"把预测压向均值"的欠拟合模型。

## 五、实验结果

### 5.1 模型对比总览

| 模型 | 人工折 CV MAE | 全数据集表现 | 说明 |
| --- | --- | --- | --- |
| **`delaynet_best.pt`**（解析式 OnsetNet + 包络门控） | **0.282 ± 0.215 μs** | 伪提前 9/37 | 首选，输出语义最贴合人工"最早脉冲" |
| `delaynet_onset.pt`（OnsetNet + 模板合成） | 0.387 ± 0.161 μs | 不伪提前，整体偏晚 | 定位稳但到达判读偏迟 |
| `delaynet_onset_e5.pt`（OnsetNet 5 成员集成） | 训练拟合 0.100 μs | 偏晚 | 集成抑制随机波动 |
| `delaynet_pseudo.pt`（DelayNet + 简单伪标注） | 4.69 ± 4.86 μs | 不伪提前 | 借无标注数据扩展覆盖 |
| `delaynet.pt`（DelayNet + 人工 ensemble=3） | 5.74 ± 3.84 μs | 全数据集最平滑 | 输出保守、相邻差最小 |

### 5.2 关键实验发现

**（1）仅看人工折精度会高估可靠性。** OnsetNet 在人工段上的表现极为突出（CV 可低至 0.10 μs，R²≈0.9999），因为它获得了逐通道到达索引的强监督。但人工段波形形态单一，模型可能只记住了该形态下的特定回波；换到形态不同的早期记录，就可能跳到后面的强回波上。这说明**必须结合全数据集行为来综合判断**。

**（2）合成数据的内容决定了模型的行为倾向。** 模板重放只用人工段波形，模型会把"某个特定回波"当成目标，遇到不同回波结构时预测偏晚（实测偏晚约 +68 μs）；解析式多回波显式教"选最早脉冲"，人工段更准，但它在没有门控时容易在噪声上乱拾起点。两条线索互相印证：模型学到什么，取决于我们教给它什么。

**（3）包络门控的收益非常显著。** 在解析式模型上叠加门控后，人工精度几乎不变（0.133 μs vs 0.136 μs），而伪提前从 28/37 降到 9/37。这验证了"信号处理粗定位 + 神经网络精修"的组合是有效的。

**（4）伪标注与人工定义的差异具有两面性。** simple 算法系统性偏晚，对逐点定位的 OnsetNet 是干扰；但对只回归 Δt 的 DelayNet，它反而扩展了样本覆盖，使精度从 5.74 μs 改善到约 4.0 μs（全数据集对比）。

### 5.3 分段行为

模型对比脚本统计了按采集时间段分组的预测均值。可以看到 DelayNet 系列的分段均值随时间平稳过渡（约 126→132→126→133→169 μs），而解析式 OnsetNet 在早期段给出更小的时延（约 90~107 μs），与它对"最早到达"的判读一致。这一差异恰好反映了不同语义假设下模型输出风格的取向。

### 6.2 推理接口

推理脚本可自动识别 DelayNet / OnsetNet 架构，支持三种使用方式：

- 对整目录批量预测并导出 CSV；
- 指定单个 `.npz` 文件预测；
- 将预测结果写回 npz 的 `labels_json` 字段。

### 6.3 可视化复核 GUI

`delaynet.gui_predict` 沿用配套手动标定工具的暗色布局，提供两个页面：

- **单条波形页**：叠加原始 CH1/CH2、预测到达标记、人工标定标记与 Δt 区间；下方同步显示 OnsetNet 两通道到达概率热图与包络门控边界（DelayNet 无热图，改用包络起点作为推断锚点）；结果栏给出预测 Δt、频率、逐通道到达时刻及与人工标定的误差着色。
- **数据集总览页**：对目录内全部记录批量预测，绘制预测 Δt 曲线并叠加人工标定点，统计 MAE / RMSE / 最大误差，支持导出 CSV。

界面顶部可切换检查点（自动识别架构）、计算设备（auto/cpu/cuda/mps），并支持方向键切换波形、勾选控制各图层的显示。这使人机协同复核成为可能：模型给出候选到达点，实验人员可快速确认或修正。

## 七、结论

本工作围绕时差法声速测量中的脉冲差识别问题，完成了从数据构造、模型设计到实验验证的完整闭环。

- **DelayNet** 以端到端回归的方式直接给出 Δt，输出平滑、行为保守，适合追求稳定性的场景；
- **OnsetNet** 通过"到达位置热图 + soft-argmax"把 Δt 拆解为两次到达定位，配合解析式多回波合成与包络门控，在保持亚微秒精度的同时，输出语义与人工"首达波"判读高度一致，是当前首选方案；
- **模板合成、解析式合成、真实增强、伪标注** 构成一套互补的数据构造体系，使 17 条人工标签也能训练出可用的深度模型；
- **连续分折交叉验证 + 全数据集行为** 的双维度评估，为小样本条件下的模型选择提供了可靠依据；
- **可视化复核 GUI** 把模型预测转化为直观的波形标注，使 AI 识别结果能够无缝接入声速测量实验的人工复核流程。

综上，本模型模块能够自动、稳定地完成时差法脉冲间隔的识别，为 AI+声速测量实验提供了核心的智能信号处理能力。

## 图2：游标卡尺机器视觉读数流程图（caliper_flow.png）

> 绘制一张"游标卡尺机器视觉自动读数流程图"，采用纵向流程图风格，配色以蓝白灰为主、专业简洁。流程分左右两条分支并行处理，最终汇合输出结果。16:9比例。
>
> **左侧分支——整数部分识别**：
> 步骤1「图像采集」：1080P工业摄像头拍摄游标卡尺 → 步骤2「图像预处理」：灰度化 → 自适应高斯阈值二值化 → 形态学闭运算（填补刻度线断裂） → 步骤3「刻度线提取」：霍夫概率直线检测提取垂直刻度线 → 轮廓检测筛选有效线条 → 步骤4「数字OCR识别」：EasyOCR识别主尺刻度数字 → 以游标零刻度线为基准、匹配最近的主尺整数刻度 → 统计刻度数量合成整数毫米读数（在旁标注：准确率>99.9%）
>
> **右侧分支——小数部分识别**：
> 步骤1「加载预设坐标」：加载预标定的游标刻度坐标序列 → 步骤2「对齐检测」：计算每条游标刻度线与主尺刻度线的像素欧氏距离 → 选取偏差最小的对齐刻度线 → 步骤3「小数计算」：按0.02mm/格精度输出小数部分读数
>
> **前置模块——相机标定（顶部横幅）**：
> 张正友单棋盘格标定法 → 求解内参与畸变系数 → 最小二乘法+LM迭代算法 → 重投影误差<0.02mm → 建立像素坐标与物理尺寸映射关系
>
> **最终汇合（底部）**：
> 整数读数 + 小数读数 → 合并输出完整游标卡尺读数值（标注：单张处理<100ms）
>
> 各步骤用圆角矩形框表示，箭头连接流向，关键精度指标用强调色标注。

## 图3：SCPI协议远程通信流程图（scpi_flow.png）

> 绘制一张"SCPI协议远程通信流程图"，纵向步骤流程图风格，蓝白灰专业配色，每一步配有简洁说明文字。整体比例16:9。
>
> 画布左侧是计算机（标注 Python + pyVISA），右侧是数字示波器（标注 OWON系列 SCPI），中间用双向箭头表示"IP / USB连接"。流程分5步从上到下排列，每一步在左右两侧各展示对应的行为：
>
> **步骤1「连接设备」**：左侧：计算机发起VISA连接请求 → 右侧：示波器响应*IDN?指令，返回设备标识，确认在线状态
>
> **步骤2「参数配置」**：左侧：发送SCPI配置指令 → 右侧：初始化通道CH1/CH2、配置采样率、时基档位、电压档位、设置触发模式与触发电平
>
> **步骤3「发送指令 & 读取数据」**：左侧：根据实验模式发送SCPI查询指令。①驻波法→ :MEASure:VPP? 读取峰峰值 ②相位法→ 采集双通道波形数据计算相位差 ③时差法→ :MEASure:TDELta? 读取时间差 → 右侧：示波器返回对应测量数据
>
> **步骤4「波形数据获取」**：左侧：发送 :WAVeform:DATA? 指令 → 解析返回的波形采样数组 → 存储波形数据 → 右侧：示波器返回完整波形采样数据
>
> **步骤5「数据校验」**：左侧：校验数据有效性与完整性 → 异常则重新采集 → 校验通过后写入MySQL数据库 → 通过WebSocket推送至前端展示
>
> 流程图右侧用文本框标注：消除人眼判读主观误差 / 支持三种实验方法自动切换 / 指令与数据同步延迟<100ms
